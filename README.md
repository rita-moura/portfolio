# Portfólio · Rita Moura

Site pessoal com minha experiência, projetos, stack e formação como desenvolvedora full-stack.

**No ar:** https://rita-moura.github.io/portfolio/

## Stack do site

HTML e CSS puros, sem build. Fontes do Google Fonts (DM Sans e DM Serif Display). Tema suave em creme, verde-sálvia e rosa pastel, com ilustração de crochê em SVG e detalhes inspirados em pontos feitos à mão, com layout responsivo.

## Rodando localmente

```bash
python3 -m http.server 8000
# abra http://localhost:8000
```

## Estrutura

- `assets/rita-moura-mark.svg`: monograma vetorial usado na marca e no favicon
- `index.html`: conteúdo
- `style.css`: estilos e tokens de tema

A seção de projetos apresenta trabalhos pessoais. A experiência profissional é descrita de forma geral, sem detalhes internos ou métricas de repositórios privados.
